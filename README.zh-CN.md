## 这是什么

一个手机上的纯文本编辑器，改配置、看日志、写脚本、随手记两行都行——打开、改两行、存回去，
文件不该有任何变化。

- **改完还是原样**：GBK 的老配置改完还是 GBK，CRLF 的脚本改完还是 CRLF——不为了改两行就把文件
  换个格式
- **不用开电脑**：服务器配置、`.env`、启动脚本、日志这些平时只能开电脑改的文件，手机上打开就能改
- **大文件也能翻**：几十万字的日志自动切成只读浏览，翻页、搜索、跳转照常，不用为了看几行去开电脑
- **免费开源，没有账号，不联网，也不要存储权限**：读写全部经由系统文件选择器给你的那一次授权

## 下载

到 [Releases](https://github.com/groundgrounder/TextNote/releases) 下载最新的 `TextNote-vX.Y.Z.apk`。

- 支持 Android 8.0（API 26）及以上
- 应用不在应用商店上架，首次安装时系统会要求你允许「安装未知来源的应用」

## 功能

**文件**

- 打开：在文件管理器里点一份文本文件，选「用 TextNote 打开」；在别的应用里**分享**过来也一样
- 新建：点「新建文件」，定好位置和名字就能开始写
- 不改编码 / 换行符：UTF-8、GB18030、GBK、带 BOM 的 UTF-16 都能读，存回时还用原来那一种；
  一个文件里混着几种换行符时会告诉你
- 最近文件：打开过的留在首页，重启后接着改。不要的条目可以移出列表（文件本身不动）；
  读不了的会标出来，点一下按提示重新授权即可
- 留住改动：它不会自作主张写你的文件，**你按保存才写**；但切到后台会先把草稿存在应用内部，
  进程被回收也不丢，下次打开问你要不要恢复。草稿保留 30 天，快到期时首页会提醒
- 文件被别的应用改过：告诉你，但不动你正在看的内容
- 能读多大：6.4 万字符以内随便改；再大就不着色，并提示输入可能变慢；超过 20 万字符切成只读浏览；
  超过 4 MB 不打开——这个体积读进内存会把应用撑爆
- 不是文本的文件（一堆 NUL 字节和控制符）会说清原因再拒收，不会甩给你一屏天书；比如不带 BOM 的
  UTF-16 会被认成二进制，在别的工具里转成 UTF-8 就能打开

**编辑**

- 撤销 / 重做：连续打字算一步，没得撤时按钮变灰
- 查找替换：显示第几处 / 共几处，可循环查找，能只换这处也能一次全换；支持正则、区分大小写、
  整词，替换串里可以用 `$1` 引用捕获组
- 接上键盘可以用 `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做
- 底部一直显示这份文件的底细：编码、换行符、语法、问题数、行列号、字数与行数

**着色**

- 34 种语言的语法高亮，认文件名——`Makefile`、`Dockerfile`、`CMakeLists.txt`、`.gitignore`
  都认得；也能自己指定，而且记得住，同一个文件下次打开还是你选的那门
- `.diff` / `.patch` / `.rej` 按行首的 `+` `-` 上色，改了什么一眼看得到
- 行号栏

**JSON**

- 边写边校，全部在设备上完成、不联网：第一处错误直接标在正文上，状态栏显示有几处问题，
  点一下跳过去并说清错在哪
- `.jsonc` / `.json5` 按宽松规则校：注释和尾随逗号都允许

**多窗口**

- 一块窗口一份文档：系统分屏或平板的桌面窗口里可以同时开好几块，各改各的
- 再开一块：长按最近列表里的文件，选「在新窗口打开」；同一份文件不会开第二个编辑器，
  免得两边各改各的互相覆盖

**界面与语言**

- 跟随系统 / 浅色 / 深色，支持跟随壁纸取色（Android 12 及以上）
- 字体、字号、行距都能调，长行折行也可以关（关掉就横向滚动）
- 界面语言四种：简体中文、繁體中文、English、Latina；默认跟随系统，也能在设置里切
